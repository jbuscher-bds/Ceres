# Media Assets for README

Place your demo recording and screenshots in this folder before or after publishing to GitHub:

- `demo.gif`: Short 10–15 second screen recording showing global hotkey dictation (`Ctrl + Shift + Space`) into an active app with the floating pill and polished output.
- `screenshot-dashboard.png`: Screenshot of the Ceres Qt 6 dashboard (`Dictate & History` or `Settings` tab).

Recommended lightweight Windows capture tools: **ScreenToGif** or **ShareX** (export at ~15 FPS, 960 px width to keep file size under 5 MB).
